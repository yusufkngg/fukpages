# Özellik denetimi — FukPages 0.2

Kullanıcının yüklediği metnin bütün özellik satırları ve dört tamamlanma ölçütü bu rapora işlendi. Sondaki sıralama tablosu iş paketlerinin tekrarından oluştuğu için ayrı özellik sayılmadı; özgün metin `REQUESTED_FEATURES.md` içinde korundu. Toplam 155 kontrol maddesi vardır.

**Bu rapor tüm maddelerin canlı ortamda tamamlandığı iddiası değildir.** Kullanıcı Shopify bağlantısını bu aşamada erteledi; AI ve e-posta/CRM sağlayıcısı seçilmedi. Yerel katalog/sepet gerçek Shopify ödeme akışı değildir. Kod incelemesi, fixture/transport testi ve gerçek Chromium kontrolü aşağıdaki kanıtlarda açıkça ayrılır.

## Doğrulama

- `npm test`: 31 test; gerçek HTTP/SQLite, medya/font dönüşümü, sürüm/senkron bölüm, formlar, rol sınırları, SEO, yayın/schedule, aktarım, A/B ve test transportları.
- `npm run build`: TypeScript ve Vite üretim derlemesi.
- `npm run test:browser`: gerçek Chromium; drag/drop, responsive, kalıcı kayıt, medya/font, native pano yapıştırma, değişken font, yerel ürün/variant/stock, form, çeviri, onay ve 60 düzenin ziyaretçi oturumunda render edilmesi.
- `npm run test:network`: gerçek HTTPS ile izin verilen GitHub görselini proxy üzerinden kalıcı medya dosyasına alma. Shopify veya AI çağrısı yapmaz.
- `npm run format:check`; `npm audit --omit=dev`.

Tarayıcı testleri gerçek sağlayıcı ayarlarını temizler; geçici test şifresi/veritabanı kullanır. Gerçek yönetici hesabı veya müşteri hesabı oluşturmaz.
